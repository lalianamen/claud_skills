# claud_skills

Project skills for Claude Code. Anything in `.claude/skills/<name>/SKILL.md` loads
automatically when Claude Code runs in this repo; call it as `/<name>`.

## marketing (Anthropic, v1.2.0, Apache-2.0)
Copied from https://github.com/anthropics/knowledge-work-plugins/tree/main/marketing
(license: `.claude/skills/LICENSE-marketing`).

| Skill | What it does |
|---|---|
| `/campaign-plan` | Campaign brief: goals, audience, channels, content calendar, metrics |
| `/content-creation`, `/draft-content` | Blog, social, email, landing page, press release copy |
| `/competitive-brief` | Competitor positioning and messaging gaps |
| `/email-sequence` | Multi-email nurture / onboarding / win-back flows |
| `/seo-audit` | Keyword, on-page, technical and competitor SEO audit |
| `/performance-report` | Marketing performance report with recommendations |
| `/brand-review` | Check copy against brand voice and flag risky claims |
